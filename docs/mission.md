# 底盘手动与自动任务

## 拨杆与流程

| 右拨杆 | 左拨杆 | 行为 |
| --- | --- | --- |
| 下 | 任意 | 四轮零力矩，清除自动计时，确认自动故障并准备启动 |
| 中或上 | 下 | 自动：轮轴 12 rad/s 纯前进 4 秒，随后持续控制零速度，不重复启动 |
| 中 | 中或上 | 原手动摇杆前后/横移及拨轮小陀螺控制 |
| 上 | 中或上 | 保留原手动失能行为 |

首次启动自动前需经过一次在线右下。直接上电左下且右中/右上不会自行行驶，
会锁存 `NotArmed`；先回右下，再将右拨杆切到中/上启动。
正常切回手动会清除自动计时，再切回左下会重新开始一次完整流程。
自动完成后一直保持左下只会停车，不会周期性重复前进。

## 参数及实际速度

`applications/mission/mission_config.hpp` 中：

- `kForwardWheelSpeedRadS = 12.0f`：纯前进时各轮轮轴角速度幅值，单位 rad/s，不是车体旋转角速度。
- `kDriveDurationMs = 4000U`：按最新要求持续 4 秒。
- `kMaxControlGapMs = 5U`：自动控制调度间隔保护。

本次保留当前分支的全局 `kMaxWheelSpeedRadS = 24.0f`、功率上限 `80 W`，
以及小陀螺 `kSpinWz = 1.0f`、手动最大平移目标 `4 m/s`、四轮 PID 输出上限 `3.0 N*m`。
控制任务使用同一个 `kWheelRadiusM = 0.077f` 完成自动速度换算和麦轮解算：
`vx = 12 * 0.077 = 0.924 m/s`，对应四轮目标按左前/左后/右前/右后为 `+12/+12/-12/-12 rad/s`。
右侧负号来自安装方向，四个轮子共同让车向前，不是左右反向旋转。
理想无滑、忽略加减速时，4 秒约走 `3.696 m`；真实距离还受轮径、打滑、负载和控制误差影响。

自动阶段请求配置的轮轴角速度，按轮半径换算为车体前进速度，不使用手动摇杆的平移斜坡，
但仍经过原麦轮解算、轮速限幅、
四轮 PID、功率限制和发送前安全复查。手动平移加速度、摇杆映射、小陀螺设定和 PID 参数均未改。

## 停车与安全

- 4 秒从四轮反馈就绪、实际进入 `Running` 时计时，等待反馈不提前消耗计时。
- 到时进入 `Finished`，清除前一阶段积分，再用原速度 PID 控制四轮零速度；不是继续前进或仅撤掉力矩滑行。
- 零速度目标不代表机械上瞬间停住，真实制动时间/距离需要实测。
- 右下始终优先于自动、手动和故障，发送零力矩；软件零力矩不能代替硬件急停。
- 自动运行中的遥控失联、非法输入、轮速反馈异常或调度超时会锁存失能。
  恢复反馈、保持左下或改成手动不能绕过故障，需右下确认。
- 发送前再次检查遥控器和四轮反馈；在计算期间切换拨杆，不发送旧控制来源的运动指令。
- 切换手动/自动和自动行驶转停车时，清理旧目标、PID 历史，避免沿用之前的前进力矩。

## 文件与调试

`mission.hpp` 定义输入、状态及速度请求，`mission.cpp` 实现非阻塞状态机，
`mission_config.hpp` 保存参数；`control_task` 每周期调用，不新建 FreeRTOS 任务。
`freertos.c`、任务栈、CubeMX 初始化、Drivers、SP 库、原绘图内容均未修改。
这次只修改 `rm_dipan`，不修改云台的 20 秒自动流程，也未增加两板通信或隧道检测。

观察以下变量：

- `control_source`：`MANUAL` 或 `AUTOMATIC`。
- `mission_status.state`：`Disabled`、`WaitReady`、`Running`、`Finished`、`Fault`。
- `mission_status.fault`：首个锁存故障。
- `mission_status.started_ms`、`elapsed_ms`：本次起始时间和已行驶指令时长，后者到 4000 后保持。
- `chassis_vx_set`：车体速度请求，自动行驶时为 `0.924 m/s`；`wheels[i].data.target_speed_set` 为轮轴目标。
- `chassis_power_limit_w`、`chassis_power_scale`：原功率上限与转矩缩放系数。

主机测试覆盖 3999/4000 ms 边界、计时回绕、单次运行、主动零速停车、手动回归、
模式切换、右下优先、故障锁存，以及真实麦轮/PID/功率限制代码。传感器与 CAN 使用测试桩，
不能代替实际整车验证。首次测试应在固定支撑、轮子离地且可立即急停的条件下进行。
